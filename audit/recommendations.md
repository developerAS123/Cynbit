## 2. Technical Remediation Specifications

### 2.1 Remediating SEC-01: Zero-Trust Account Onboarding

**Vulnerability:** Raw passwords dispatched in JSON responses upon payment.  
**Fix:** Replace plaintext credential delivery with an asynchronous, cryptographically signed magic onboarding link. Passwords must never be generated by or visible to the server in plaintext.

```python
# implementation/core/security.py
import secrets
import hashlib
from datetime import datetime, timedelta, timezone
from passlib.context import CryptContext

# Industry-standard Argon2id configuration
pwd_context = CryptContext(
    schemes=["argon2"],
    deprecated="auto",
    argon2__memory_cost=65536,  # 64 MB
    argon2__time_cost=3,
    argon2__parallelism=4,
)

def hash_password(password: str) -> str:
    """Hashes a password using Argon2id."""
    return pwd_context.hash(password)

def verify_password(plain_password: str, hashed_password: str) -> bool:
    """Constant-time verification of password against Argon2id hash."""
    return pwd_context.verify(plain_password, hashed_password)

def generate_onboarding_token() -> tuple[str, str, datetime]:
    """
    Generates a secure single-use onboarding token.
    Returns: (raw_token_for_user_email, sha256_hash_for_db, expires_at)
    """
    raw_token = secrets.token_urlsafe(32)
    token_hash = hashlib.sha256(raw_token.encode("utf-8")).hexdigest()
    expires_at = datetime.now(timezone.utc) + timedelta(hours=24)
    return raw_token, token_hash, expires_at
```

### 2.2 Remediating SEC-05: Strict Security Headers Middleware

**Vulnerability:** Missing CSP, X-Frame-Options, nosniff, and wildcard CORS.  
**Fix:** Inject strict security headers on every response via an ASGI middleware.

```python
# implementation/middleware/security_headers.py
from starlette.middleware.base import BaseHTTPMiddleware, RequestResponseEndpoint
from starlette.requests import Request
from starlette.responses import Response

class SecurityHeadersMiddleware(BaseHTTPMiddleware):
    async def dispatch(self, request: Request, call_next: RequestResponseEndpoint) -> Response:
        response = await call_next(request)
        
        # Enforce modern security boundaries
        response.headers["X-Frame-Options"] = "DENY"
        response.headers["X-Content-Type-Options"] = "nosniff"
        response.headers["Referrer-Policy"] = "strict-origin-when-cross-origin"
        response.headers["Permissions-Policy"] = "camera=(), microphone=(), geolocation=()"
        response.headers["Strict-Transport-Security"] = "max-age=63072000; includeSubDomains; preload"
        
        # Content Security Policy (allows Cashfree modal script, restricts framing)
        csp = (
            "default-src 'self'; "
            "script-src 'self' https://sdk.cashfree.com; "
            "style-src 'self' 'unsafe-inline' https://fonts.googleapis.com; "
            "font-src 'self' https://fonts.gstatic.com; "
            "img-src 'self' data: https:; "
            "frame-src https://sdk.cashfree.com; "
            "frame-ancestors 'none';"
        )
        response.headers["Content-Security-Policy"] = csp
        
        return response
```

### 2.3 Remediating SEC-06: Sliding-Window Rate Limiter

**Vulnerability:** Unrestricted RPC submissions on public forms.  
**Fix:** Implement an in-memory / Redis sliding window rate limiter tracking client IP and target route.

```python
# implementation/middleware/rate_limit.py
import time
from collections import defaultdict
from fastapi import Request, HTTPException, status

class SlidingWindowRateLimiter:
    def __init__(self, requests_limit: int = 5, window_seconds: int = 60):
        self.requests_limit = requests_limit
        self.window_seconds = window_seconds
        self.history = defaultdict(list)

    def check(self, key: str):
        now = time.time()
        window_start = now - self.window_seconds
        
        # Prune expired timestamps
        self.history[key] = [t for t in self.history[key] if t > window_start]
        
        if len(self.history[key]) >= self.requests_limit:
            retry_after = int(self.history[key][0] + self.window_seconds - now)
            raise HTTPException(
                status_code=status.HTTP_429_TOO_MANY_REQUESTS,
                detail=f"Rate limit exceeded. Try again in {max(1, retry_after)} seconds.",
                headers={"Retry-After": str(max(1, retry_after))}
            )
        
        self.history[key].append(now)
```

### 2.4 Remediating SEC-07: Cashfree Webhook Signature Verification

**Vulnerability:** Relying on client-side callbacks for payment confirmation.  
**Fix:** Implement an asynchronous webhook handler that validates the Cashfree signature header using **HMAC-SHA256** before fulfilling orders.

```python
# implementation/core/security.py
import hmac
import hashlib
import base64

def verify_cashfree_signature(payload_bytes: bytes, signature: str, secret_key: str) -> bool:
    """
    Verifies that the incoming webhook payload was authentically signed
    by Cashfree using HMAC-SHA256 and constant-time comparison.
    """
    if not signature or not secret_key:
        return False
        
    expected_digest = hmac.new(
        secret_key.encode("utf-8"),
        payload_bytes,
        hashlib.sha256
    ).digest()
    
    expected_signature = base64.b64encode(expected_digest).decode("utf-8")
    return hmac.compare_digest(expected_signature, signature)
```

### 2.5 Remediating SEC-04: Constant-Time Generic Responses

**Vulnerability:** Disclosing whether an email has applied or exists in the database.  
**Fix:** Standardize response payloads across both existing and non-existing records:

```python
# implementation/api/v1/applications.py
@router.post("/", response_model=ApplicationResponse)
async def submit_application(payload: ApplicationCreate, db: AsyncSession = Depends(get_db)):
    # Look up existing submission
    existing = await get_application_by_email_and_job(db, payload.email, payload.job_id)
    
    if existing:
        # Silently record update attempt or dispatch status email
        # DO NOT expose duplicate tracking URL to unauthenticated caller
        return ApplicationResponse(
            success=True,
            message="Application blueprint received. A confirmation has been dispatched to your email."
        )
        
    await create_new_application(db, payload)
    return ApplicationResponse(
        success=True,
        message="Application blueprint received. A confirmation has been dispatched to your email."
    )
```
